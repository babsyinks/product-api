Introduction

A clean RESTful API for managing products, built with Laravel.

Base URL: http://localhost:8000

Overview

This API provides full CRUD management for the Product resource, with optional Sanctum token authentication.

Base URL

http://localhost:8000/api/v1

Response format

All responses are JSON. Successful responses follow:

{ "data": { ... } }          // single resource
{ "data": [...], "meta": {} } // collection with pagination

Error format

{ "message": "...", "errors": { "field": ["..."] } }

Auth

Public endpoints: GET /products, GET /products/{id} Protected endpoints (require Bearer token): POST, PUT, DELETE

Authenticating requests

To authenticate requests, include an Authorization header with the value "Bearer {YOUR_AUTH_KEY}".

All authenticated endpoints are marked with a requires authentication badge in the documentation below.

Obtain a token via POST /api/v1/login. Pass it as: Authorization: Bearer {token}

Authentication

Endpoints for obtaining and revoking API tokens (Laravel Sanctum).

Register

Creates a new user account and returns a Sanctum API token.

Example request:
curl --request POST \
    "http://localhost:8000/api/v1/register" \
    --header "Accept: application/json" \
    --header "Content-Type: application/json" \
    --data "{
    \"name\": \"Jane Doe\",
    \"email\": \"jane@example.com\",
    \"password\": \"secret123\",
    \"password_confirmation\": \"secret123\"
}"

const url = new URL(
    "http://localhost:8000/api/v1/register"
);

const headers = {
    "Accept": "application/json",
    "Content-Type": "application/json",
};

let body = {
    "name": "Jane Doe",
    "email": "jane@example.com",
    "password": "secret123",
    "password_confirmation": "secret123"
};

fetch(url, {
    method: "POST",
    headers,
    body: JSON.stringify(body),
}).then(response => response.json());

Example response (201):


{
    "token": "1|abc123...",
    "token_type": "Bearer"
}

Products

Endpoints for managing the product catalogue.

List products

Returns a paginated list of products. Supports full-text search, price-range and stock filters, and column sorting.

Example request:
curl --request GET \
    --get "http://localhost:8000/api/v1/products?search=headphones&min_price=10&max_price=500&in_stock=1&sort_by=price&sort_dir=asc&per_page=20" \
    --header "Accept: application/json" \
    --header "Content-Type: application/json"
const url = new URL(
    "http://localhost:8000/api/v1/products"
);

const params = {
    "search": "headphones",
    "min_price": "10",
    "max_price": "500",
    "in_stock": "1",
    "sort_by": "price",
    "sort_dir": "asc",
    "per_page": "20",
};
Object.keys(params)
    .forEach(key => url.searchParams.append(key, params[key]));

const headers = {
    "Accept": "application/json",
    "Content-Type": "application/json",
};

fetch(url, {
    method: "GET",
    headers,
}).then(response => response.json());
